# C to Python Translator

This project is a C to Python translator implemented in Java using ANTLR4. It parses C11 source code and generates equivalent Python code.

## Features

- Parses C11 grammar using ANTLR4 (`C.g4`)
- Supports variable declarations, functions, control flow, and more
- Outputs Python code with proper indentation and structure

## Project Structure

- Source files
  - `C.g4` — ANTLR4 grammar for C11
  - `CToPythonListener.java` — Custom listener for generating Python code that extends `CBaseListener`
  - `CTranslator.java` — Main entry point for the C-to-Python-Translator

- Generated files (generated by running the ANTLR4 tool on the grammar file `C.g4` - command: `antlr4 C.g4`):
  - `CLexer.java` — Lexer
  - `CParser.java` — Parser
  - `CBaseListener.java` — Base listener class
  - `CListener.java` - Listener interface
  - `C.tokens`
  - `C.interp`
  - `CLexer.tokens`
  - `CLexer.interp`

## Usage

1. **Build the project**

   Generate lexer and parser from grammar using ANTLR, then compile Java sources:
   ```sh
   antlr4 C.g4
   javac *.java
   ```

2. **Run the translator**

   Provide a C source file as input:
   ```sh
   java CTranslator <c-source-file>
   ```

   The translated Python code will be printed to the console.

3. **Visualize the parse tree (optional)**

   Provide a C source file and a start rule to visualize the parse tree:
   ```sh
   grun C <start-rule> -gui <c-source-file>
   ```

   For our C11 grammar, the start rule is `compilationUnit`, so the command would be:
   ```sh
   grun C compilationUnit -gui <c-source-file>
   ```

## Requirements

- Java 8+
- [ANTLR 4](https://www.antlr.org/)
- C source code compatible with C11

Please refer to the `The Definitive ANTLR 4 Reference` by Terence Parr for more details on setting up your development environment and using ANTLR.

The above `antlr4` and `grun` commands assume you have set up the following aliases in your shell configuration file (e.g., `.bashrc`, `.zshrc`):
```bash
# ANTLR4 aliases
export CLASSPATH=".:/usr/local/lib/antlr-4.13.2-complete.jar:$CLASSPATH"
alias antlr4='java -jar /usr/local/lib/antlr-4.13.2-complete.jar'
alias grun='java org.antlr.v4.gui.TestRig'
```
